ADDITIONAL TABLE RULES:
Inspect the visible ruling and merged cells before writing. Preserve the printed horizontal row boundaries, column headings and reading order. Several books in a cell are not necessarily several table rows. Keep their matching chapter blocks in the adjacent cell in the same order; preserve blank lines between groups using <br><br>. A separate websites cell may list general topic resources; do not assign each link to a book merely because both cells contain lists.
Use a Markdown header and separator with exactly the same number of columns in every data row. Escape a literal cell pipe as \|. Use only <br> for cell line breaks, not arbitrary HTML. If merged-cell geometry cannot be represented faithfully, keep the source grouping and record its precise limitation in uncertainties instead of inventing relationships. Never treat a diagonal watermark as a table-cell value.
